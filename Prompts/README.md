# 💡 LangChain Prompts Module

Welcome to the **Prompts Module** of the LangChain experimentation workspace! This directory is dedicated to creating, testing, and managing reusable prompt templates using LangChain.

## 📁 Directory Contents

### `prompt_ui.py`
A beautiful and interactive **Streamlit Web Application** that acts as the front-end for our prompt experimentation. 
- Allows you to select a research paper, explanation style, and explanation length.
- Dynamically loads the JSON prompt template.
- Uses the `gemini-2.5-flash` model via Google Generative AI to generate personalized, tailored summaries on the fly.
- **To run:** `streamlit run prompt_ui.py`

### `prompt_generator.py`
A utility script used to author and serialize complex prompts. 
- Defines a comprehensive `PromptTemplate` incorporating best practices (clear instructions, formatting rules, analogies, and mathematical simplification).
- Saves the template directly into a reusable JSON format, decoupling the prompt logic from the UI application code.

### `research_paper_summary_template.json`
The serialized prompt template generated by `prompt_generator.py`. This artifact is dynamically loaded by `prompt_ui.py` when generating inferences. This ensures our prompt design can be version-controlled and modified independently of the application's runtime code.

### `chat_prompt_template.py`
A simple script demonstrating how to use `ChatPromptTemplate` to structure a conversation with multiple roles (e.g., system, human).
- Shows how to format input variables dynamically before invoking the model.

### `chatbot.py`
A basic CLI-based interactive chatbot script utilizing LangChain's message structure (`HumanMessage`, `SystemMessage`, `AIMessage`).
- Employs Hugging Face's `Qwen/Qwen2.5-72B-Instruct` model via `HuggingFaceEndpoint` and `ChatHuggingFace` for generating responses.
- Maintains and passes chat history in memory for context-aware conversations.
- **To run:** `python chatbot.py`

### `msg_placeholder.py`
A script demonstrating the use of `MessagesPlaceholder` to dynamically inject previous conversation history into a prompt template.
- Demonstrates loading existing chat history from an external text file (`chat_history.txt`).
- **To run:** `python msg_placeholder.py`

### `chat_history.txt`
A text file storing simulated chat history (e.g., previous `HumanMessage` and `AIMessage` objects) to test the dynamic loading of context in `msg_placeholder.py`.

## 🚀 Getting Started

1. Ensure your environment variables are configured in the root `.env` file (e.g., `GOOGLE_API_KEY`).
2. Generate the prompt template (if not already present):
   ```bash
   python prompt_generator.py
   ```
3. Launch the Streamlit User Interface:
   ```bash
   streamlit run prompt_ui.py
   ```
   
> **Note:** The UI uses dynamic absolute path resolution to ensure it can successfully load the prompt template regardless of where you execute the Streamlit command from!
