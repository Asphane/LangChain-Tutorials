# Retrievers in LangChain

This folder contains notebooks and examples (`retrievers.ipynb`) demonstrating how to use Retrievers in LangChain. 

## Overview
Retrievers are interfaces that return documents given an unstructured query. This section explores:
- Setting up vector stores for semantic search.
- Using different types of retrievers (e.g., VectorStore-backed retrievers).
- Integrating retrievers into conversational and Q&A chains.
